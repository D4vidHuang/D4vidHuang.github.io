Privacy on this site.

This page explains how the website is hosted and which external assets load when you open it. The site does not use analytics scripts.

Services used to display the page

  • GitHub Pages hosts the website and may process ordinary connection logs under the GitHub Privacy Statement.
  • Google Fonts supplies the typefaces on both pages. The homepage also loads its animation scripts from cdnjs. Visiting either page sends standard asset requests to the providers it uses.

What this site stores

The website's own code sets no cookies and writes nothing to local storage. It does not collect raw IP addresses, individual browsing histories, or precise locations. The Google Scholar numbers come from a published snapshot of a public profile and contain no visitor information.
