Privacy · 10 September 2026

A small site with limited analytics.

This page explains which external services the website contacts, what the visitor display means, and how to avoid loading the optional location widget.

Services loaded with the page

  • GitHub Pages hosts the website and may process ordinary connection logs under the GitHub Privacy Statement.
  • Google Fonts supplies the typefaces, and cdnjs supplies the optional animation library. Visiting the page sends a standard asset request to those providers.
  • CounterAPI supplies the unique-visit total. It says IP addresses and browser details are transformed into non-identifying hashes. The site receives only an aggregate number.

Optional live location map

The Whos.amung.us map is off by default. Its code loads only after you press “Load live visitor map.” When loaded, the provider receives data such as your IP address, page URL, referrer, browser, and operating system, and may load supporting partner services. See the Whos.amung.us privacy policy before opting in.

The map covers only visitors who choose to load it. It is not a geographic breakdown of the separate unique-visit total. To opt out, simply leave the map unloaded.

What this site stores

The website's own code sets no cookies and writes nothing to local storage. It does not receive or store raw IP addresses, individual browsing histories, or precise locations. The Google Scholar numbers are a server-side public-profile snapshot and contain no visitor information.
